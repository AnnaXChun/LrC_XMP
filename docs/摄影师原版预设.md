## 使用与再分发依据

作者在[下载与开放使用说明](https://erickimphotography.com/blog/downloads/)中将网站信息称为免费、开放内容，并写明：

> You can remix it, translate it, or sell it for a profit.

该页同时列出 Lightroom 预设。这里依据作者公开许可说明保留和分发其发布的 XMP，不擅自替作者指定 MIT、CC0 等标准许可证。

作者在[早期发布说明](https://erickimphotography.com/blog/2017/07/11/free-eric-kim-lightroom-presets/)致谢 VSCO，并说明自己优化、修改过既有配方。因此本项目采用“Eric Kim 本人发布”这一表述，保留该来源链，不称其为完全原创参数。Portra、Neopan 等名称沿用原文件，不表示胶片厂商的官方产品。

原始压缩包留在忽略目录；公开仓库只收录所用六份 XMP 与对应记录。样张来自独立的公共许可来源，不是 Eric Kim 的作品。

## 本次对照说明

使用同一批温室、咖啡、人像和傍晚照片，分别应用六份原件，得到 24 张 Python 近似结果。加上两份历史参考，共 32 张。

原件包含固定曝光：Color 1600 v10 为 +1.59，Monochrome 1600 为 +1.15。这些数值在本次已渲染 JPEG／PNG 上仍直接参与计算，所以部分亮部明显裁切；没有为样图降低曝光或重写预设。

Portra 800 v2 的结果相对较暗；Neopan 1600 的灰阶比 Monochrome 1600 的深影更柔。这些描述仅针对本次 Python 输出。颗粒、相机配置、RAW 白平衡、锐化、降噪及其他缺项见逐图报告，不能把结果当作 Adobe 渲染或胶片模拟精度的验证。
