# 预设收录与制作约定

用户当前要求使用摄影师实际发布的预设。新增收录先核实作者和原文件，不能凭作品观感自行编排参数。

## 来源分类

| 目录 | 含义 |
| --- | --- |
| `presets/photographers/` | 摄影师本人或明确授权渠道发布的原文件；保留原始字节 |
| `presets/confirmed/` | 有具体数值来源的教程复现；被模仿的摄影师不等于教程作者 |
| `presets/partial/` | 用户笔记等资料不全的参考；未确定设置保持缺省 |
| `archive/self-authored-studies/` | 历史项目自制研究，退出默认列表与当前交付包 |

默认不新增自制仿色配方。用户以后明确要求自行设计时，另建研究范围和说明，不能混入摄影师本人预设。

## 收录原文件

1. 找到作者本人网页或可核实的授权发布页，记录直接链接。
2. 从该页面公开列出的渠道下载，不采用来源不明的搬运包。
3. 核实使用与再分发依据。没有公开再分发依据的文件，不上传公共仓库；可记录官方获取入口。
4. 保留原始文件名、名称、UUID、全部数值与曲线，记录压缩包哈希和内部路径。
5. 与原包成员逐字节核对，并生成同名 `.source.json`、`.verification.json`。
6. 本地软件不支持的字段保留在原件里，预览报告逐项列出。不能为了让图片更好看删改原参数。

作者声明由其他配方修改的，保留其致谢和来源说明，只称“本人发布”，不改称“完全原创”。作者为照片设置的固定曝光和白平衡也必须保留。

## 教程与用户数值

用户指定值原样保留，未指定设置不补默认值。曲线逐点记录；估算锚点不能冒充教程读数。复用时需要变体，另用名称和 UUID，不覆盖既有文件。

`confirmed` 只表示参数有来源，不表示 Lightroom 已验证。主版来自 LeoCarbin 的品川力仿色教程，不能称为品川力本人预设。

## 验证与样图

文件检查包含 XML／RDF、所有字段、曲线、元数据、UUID 与 SHA-256。照片处理采用副本，原图不变。默认发现仅遍历 `presets/`，不能把归档加入默认试色。

新增文件后重跑当前全部预设，更新 README、样图、报告和下载包。保留失败或不适合的结果，说明输入与原配方的限制。

Lightroom 实测需要已有授权环境，在测试副本上导入、确认面板可见、应用并读回参数。安装前确认实际预设目录；重启前征求同意。Python 预览与 Lightroom 实测分别报告。

公开样张遵循来源许可。原始下载文件、个人照片、凭证和本地缓存不随仓库发布。
